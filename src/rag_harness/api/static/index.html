    About this demo

    This is a portfolio demo. The service is deliberately capped so a public demo cannot run up a surprise bill:

    • Per-IP rate limit: 10 requests per hour, 3 per minute burst.
    • Global daily cap: 200 requests per day (resets at 00:00 UTC).
    • Monthly Cloud Billing ceiling: $10.

    If the demo has hit the daily cap you’ll see a friendly notice; try again after 00:00 UTC. Corpus is a pinned snapshot of the Kubernetes documentation; answers may not reflect the very latest upstream changes.
